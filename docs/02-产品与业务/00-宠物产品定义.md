# 宠物产品定义与参考比较

更新时间：2026-09-09 14:29（Asia/Shanghai）

## 用户边界

复用本机 Codex 完整内置宠物图集；创建使用随插件提供的 DSH 适配 Skill；Web 只在网页中；Desktop 可在桌面上。参考仓库只用于需求与行为比较，所有业务和渲染代码独立实现。

本轮完整性基准为 Codex 26.901.6511.0：检查安装资产索引并匹配 9 只原始图集，与用户截图一致。未来 Codex 增加宠物时需要更新清单，不能将本轮 9 只断言为所有未来版本。

## 用户流程

1. 设置 → 宠物 → 选择角色，即时展示并保存。
2. 通过收起按钮暂时隐藏，在设置恢复；Web 位置和 Desktop 屏幕位置分别保存。
3. 点击创建 → 输入描述 → 在 DSH 新会话中执行随包 Skill → 完成后刷新宠物库。
4. 宠物气泡提示任务状态；点击气泡打开关联任务。交互动作结束后回到真实业务状态。

设置视觉以 [用户原图](../01-当前工作/I001-Codex宠物双端实现/01-Codex参考.png) 为准，浅色主题采用 DSH 的颜色变量，窄屏允许操作区换行。

## 多会话管理

宠物管理通知列表，支持展开、关闭恢复、排序、按轮次保留、直接审批和问题/计划回答，点击跳转对应会话。详见 [行为与验收](../01-当前工作/I001-Codex宠物双端实现/16-多会话验收.md)。

当前交互已按用户反馈精简：移除新会话下拉和消息输入区。新建与继续聊天使用 DSH 主界面，宠物专注通知与待处理事项。
