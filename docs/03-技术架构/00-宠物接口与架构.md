# 宠物接口与架构

更新时间：2026-09-09 14:29（Asia/Shanghai）

## 模块职责

| 模块 | 职责 |
|---|---|
| `src/model.ts` | 宠物/配置/任务协议，9 动作逐帧时间和 16 方向注视 |
| `src/library.ts` | 原图和自定义目录读取、尺寸验证、路径边界、原子配置保存 |
| `src/creation.ts` | DSH 会话创建与 Skill 请求，RPC 拒绝处理 |
| `src/index.ts` | DSH Host 注册、HTTP 接口、固定资源路由 |
| `src/client.tsx` | settings.section / shell.overlay 插槽和 Session 订阅 |
| `src/ui.tsx`、`src/styles.ts` | 共用设置、图集、交互及 Skill 指令交接 |
| `src/standalone.tsx` | 原生窗口渲染入口 |
| `scripts/import-codex.ts` | 原图提取和来源 SHA256 记录 |
| Desktop `src/pet-window*.ts` / `.cts` | Electron 窗口、边界策略、有限 preload 桥接 |

Desktop 在主 DSH WebContents 暴露 `dshDesktopPet.sync/onAction`，数据经主进程验证后发送给独立透明窗口；窗口仅接受本机同源 `/dsh-codex-pet/desktop.html`。Web 无该桥接时渲染页面浮层，有桥接时不重复渲染；同步失败显示错误。

原生容器 320×560，给最大 224 宠物、气泡与菜单留出空间。按显示器工作区约束坐标；空白区域穿透，按钮区域接收输入。退出/卸载时注销 IPC 和屏幕事件。

## HTTP 接口

基路径 `/dsh-codex-pet`。所有 API 成功返回完整 `Library` 快照：`pets`、`config`、`customPath`、`warnings`、`skillAvailable`、`creationAvailable`、`creation`。字段定义以 `src/model.ts` 为准。

| 方法 | 路径 | 输入 | 行为 |
|---|---|---|---|
| GET | `/api/state` | 无 | 当前快照，不扫描磁盘 |
| POST | `/api/config` | 部分 Config | 校验并串行合并保存，返回确认后的配置 |
| POST | `/api/refresh` | `{}` | 重扫原版和自定义图集 |
| POST | `/api/create` | `{ "description": "…" }` | 已停用，返回 400；前端改用 DSH 会话服务 |
| POST | `/api/open-folder` | `{}` | 仅本机请求可打开固定自定义目录 |
| GET | `/asset/:id` | URL 编码的宠物 ID | 已注册 PNG/WebP 图集 |
| GET | `/preview.html` | 无 | 已移除，返回 404 |
| GET | `/desktop.html` | 无 | 原生容器渲染入口 |
| GET | `/standalone.js` | 无 | 白名单前端构建资源 |

POST 要求 `Content-Type: application/json` 和 `x-dsh-pet: 1`，Origin 若存在必须与 Host 一致，拒绝 cross-site；Host 限 `localhost`、`127.0.0.1`、`[::1]`。不支持直接以远程域名访问本插件。接口注册在 DSH WebServer 内，未增加另一套账户系统；本地独立预览仅监听回环地址。

错误结构 `{ "error": "说明" }`；400 为参数、资源校验或操作错误，403 为来源拒绝，404 为未知路径，405 为方法不支持。API 响应不缓存，请求体上限 16 KB。创建不是幂等操作，以单任务互斥拒绝重叠执行；配置更新按队列处理，临时文件成功替换后才发布新状态。

## 数据边界与验证限制

内置原图只读，自定义 `pet.json` 上限 64 KB、图集上限 32 MB；realpath 检查拒绝链接越界。几何检查不能代替图像解码、透明度和逐帧视觉验收，这些由原版 hatch-pet 负责。

配置默认写 `${DSH_HOME}\codex-pet\config.json`，Web 保存 0–1 归一化位置；Desktop 写自身 userData 下 `pet-position.json`。不共享桌面像素坐标与网页坐标。

当前自定义库刷新需用户点击刷新，后台配置轮询不等于磁盘自动发现。任务等待优先，其次错误、完成和运行；其他任务错误依赖宿主可用摘要，当前会话有详细快照。未配置模型的隔离环境只验证插槽和状态选择单测，不代表真实模型任务全部通过。

## 会话状态适配

src/activity.ts 仅声明宿主快照契约；src/notifications.ts 管理多会话通知生命周期、排序与请求身份校验。src/notification-tray.tsx 是双端共用列表和审批/回答界面。client.tsx 接入 DSH 会话发消息；独立预览不提供宿主会话。

Desktop notificationsVersion=2 提供通知状态及命令结果回传；旧桥接回退网页。完整行为和已验证范围见多会话验收记录。

## 独立运行基线

资源与 Skill 随插件打包。PetLibrary 自定义目录为 dataRoot/pets，Skill 来自插件 skills/hatch-pet；不再访问 CODEX_HOME 或探测 Codex CLI。创建通过 DSH sessions.create/open、session.prompt，生成完成后刷新。旧 CLI 创建协议不再生效。
